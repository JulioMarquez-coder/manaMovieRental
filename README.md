# Mana Movie Rental System

Mana Movie Rental System is a collaborative Java project created as an academic assignment. The application was developed to manage a movie rental system, allowing users to work with movie information and rental-related features.

## Technologies Used

- Java
- NetBeans
- MySQL
- GitHub

## Features

- Movie rental system developed in Java
- Database connection using MySQL
- Organized source code inside the `src` folder
- Image resources included in the project
- Collaborative development using GitHub

## How to Run

1. Download or clone this repository.
2. Open the project in NetBeans.
3. Make sure MySQL is installed and running.
4. Import or create the required database for the project.
5. Update the database connection settings if needed.
6. Locate the main Java file inside the `src` folder.
7. Run the project from NetBeans.

## Project Type

This was a collaborative academic project.
